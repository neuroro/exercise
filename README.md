# neuroro/exercise
Resistance exercise code

# onerepmax.py
Calculate one repetition maximum and equivalent loads for sets of up to 12 repetitions from the load and repetitions of the last completed heavy working set, using validated (Simonsen, 2025) estimates of one repetition maximum and the expected value of the inverses of the estimates weighted by the inverse of the normalised mean absolute error (Simonsen, 2025), rounded to 1.25 kg
